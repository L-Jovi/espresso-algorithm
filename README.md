# Espresso Algorithm

English | [简体中文](README.zh-Hans.md)

Try different algorithms for the same problem, from brute force to optimal. Pure concentration, like an espresso.

> **Being reorganized (September 2026).** The folders are moving to a new layout: sorting, searching, data structures, classic problems and LeetCode, each with tests and its own README. Until that is finished, the old scripts in the folders that have not been converted may not run. The [migration ledger](docs/migration.md) shows where every file went.

## Run the tests

```sh
git clone https://github.com/L-Jovi/espresso-algorithm.git
cd espresso-algorithm
npm test
```

There is nothing to install: the repository has no dependencies. You need Node.js 22.18 or newer; Node 24 LTS is recommended.
