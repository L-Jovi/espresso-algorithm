Race the solutions

Fifteen LeetCode problems, each solved several ways. Pick one and race its approaches on the same input, in your browser, with the code the tests check.

十五道 LeetCode 题，每道都有几种解法。选一道，让它的各种解法在你的浏览器里、用同一份输入、以测试检查过的同一份代码比赛。

Each time is per call, measured in a background thread of this page: the fastest of three runs for slow approaches, and the average of repeated calls for fast ones, because browsers round their clock. A dash means the approach sits this input out: it would take minutes or overflow the call stack. Your numbers depend on your device and change between runs; the large gaps between the rows stay. npm run bench:leetcode runs the same races in Node.

Part of Espresso Algorithm: try different algorithms for the same problem, from brute force to optimal. MIT licensed.
