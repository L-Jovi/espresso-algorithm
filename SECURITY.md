# Security

This repository holds learning code, not a library or a service. There are no releases; only the `main` branch is maintained. Nothing here is meant to process untrusted input in production.

If you find something that could harm a person who runs the code, for example a script that writes outside the repository or runs a command it should not, report it privately through [GitHub's private vulnerability reporting](https://github.com/L-Jovi/espresso-algorithm/security/advisories/new). Please do not open a public issue for it.

Wrong answers, crashes and slow solutions are ordinary bugs: open a [wrong answer report](https://github.com/L-Jovi/espresso-algorithm/issues/new?template=wrong-answer.yml) instead.
