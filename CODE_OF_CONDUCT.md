# Code of conduct

Be patient, specific and kind. Discuss code, inputs and evidence; do not attack the person who wrote them. Harassment, discrimination and sharing someone else's private information are not welcome here.

The maintainer is [Jovi](https://github.com/L-Jovi). If something in an issue, pull request or comment needs moderation, open an issue that describes the problem without repeating the offending material. The maintainer may edit or remove harmful content and restrict people who keep disrupting the project.
